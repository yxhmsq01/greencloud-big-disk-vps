## 绿云大盘鸡到底是什么

绿云大盘鸡是 GreenCloudVPS 的 Storage 存储型 VPS 产品线，基于 KVM 虚拟化，用大容量企业级 SATA 硬盘做硬件 RAID-10，部分机房配小容量 NVMe 做系统启动盘，端口统一 10Gbps。每台默认分配 1 个 IPv4 和 /112 或 /64 的 IPv6，系统仅支持 Linux，控制面板为 VirtFusion。

这个产品线的思路很直接：牺牲硬盘的随机读写性能，换取每 TB 极低的成本。机械盘 RAID-10 跑不动高 I/O 的数据库，但放备份、归档文件、网盘附件绰绰有余。绿云从 2013 年运营至今，官网称其在美国特拉华州注册、硬件全部自有；第三方综述则提到它在北美、西欧和亚太铺开了 30 多个机房，其中就包括对存储用户很关键的东京和新加坡。在存储 VPS 横评中，它曾排在 RamNode、VPSDime 这类老牌存储商前面，Storage-0.5TB 拿到过对比页内的最低首价。Trustpilot 上它有 3.7 分（120 条评论），中等偏上，算不上惊艳，但符合老牌低价商的常态。

要提醒的是，这是非托管服务。官方只负责母机稳定和网络在线率，系统里的软件问题不归客服管，出问题要靠自己排查或找社区。

## 大陆访问和性能表现：预期要放对位置

常规大盘鸡套餐到中国大陆没有线路优化，走标准国际 BGP，晚高峰时段直连访问容易出现延迟升高和丢包。想买大陆优化线路，要看绿云单独标注 CN Premium Optimized 的产品线，那批机器贵不少，也不属于大盘鸡系列。做纯备份的话这个问题影响有限，毕竟 Rsync 和 Restic 大多在夜间跑，对延迟不敏感；但如果你的网盘要经常从国内直接访问，最好前置一层 CDN 或中转机，或者优先考虑日本 SoftBank 特价线。

性能上限也有参考数据。2022 年有博主对绿云东京一款小盘鸡做过测试，网速没有跑到标称千兆口的一半，晚高峰 ping 值也有波动；更近期的日本特价机评测提到 CPU 跑分“超售情况比较明显”，同时补了一句“考虑到低价大盘机的定位，整体还是相当有吸引力”。把这些放在一起看，预期就清楚了：机械盘 RAID-10 的顺序读写对备份够用，但别拿它当高性能盘使，数据库和高 I/O 场景请绕行。

CPU 限制同样写在条款里：连续 30 分钟以上占满 100% vCPU（长时间视频压制、大型编译这类负载）会被限速甚至强制关机。大盘鸡的 CPU 本身就是配角，1 到 4 核多为共享核，适合它干的活就是备份脚本、下载机和文件服务。
